# Refleksjonsnotat - Fisketur

## Formål
Jeg utvikler Fisketur for å hjelpe familier og andre frilufts mennesker å planlegge eller utforske Fiskevann i Telemark og Sørmyr området.

Ideen bygger på en personlig opplevelse der en bom førte til lengre gåtur enn forventet med et lite barn. Jeg ønsker derfor å gjøre denne informasjonen tilgjengelig slik at det blir lettere å planlegge en slik tur for andre.

## Undersøke datakilder
Jeg undersøkte datakilder med hjelp fra KI og valgte NVE som hoved API. Fant ut at informasjon om bommer, nøkler og fiskearter må suppleres med andre kilder.
## Opprette prosjektet
Jeg opprettet prosjektet med Next.js og Typescript. Jeg valgte å bruke vanlig CSS og CSS modules. 
## Sider og navigasjon
Jeg lagde hoved-side, fiskevann-side og om-side. 
Lagde en felles header med navigasjon
## Git og Github
Jeg brukte Git til å lagre utviklingen og koble det til Github.
## Hente data fra API
Jeg lagde en funksjon som henter innsjøer fra NVE. 
## Vise fiskevann
Jeg koblet hentefunksjonen til fiskevann siden og brukte map til å vise navn og areal.
La også inn tekst som vises dersom informasjon mangler.
